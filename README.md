# こぼれる

> 大切な人が多すぎるとね
> 手から零れ落ちちゃうの
> 分かるかな

それを体で分かるための、スマホ向けの小さな体験型ゲーム。

**遊ぶ:** https://bubbleshaker.github.io/koboreru/

## 遊び方

- 画面をなぞって両手を動かし、降ってくる「大切な人」を受け止める
- 手の中の光は少しずつ弱まる。光に触れ続けると想いが届いて光が戻る（そのあいだ手は動かせない）
- 手の中が混み合うほど、ひとりひとりの光は早く弱まる。急いで動けば、手が傾いて零れ落ちる
- 約100秒。スコアはありません

最初に自分の大切な人の名前を入れることもできます（端末の中だけで使われます）。

依存なしの静的サイト（Canvas 2D + Web Audio）。
